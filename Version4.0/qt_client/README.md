# NetDisk Qt 客户端

这是基于 Qt Widgets 的基础网盘客户端，复用 `Version4.0` 服务端的 TLS 和长度分帧协议，不影响原命令行客户端。

## 当前功能

- 登录、注册并登录；
- 独立注册模式、确认密码和返回登录；
- TLS 连接；
- 首页工作台、最近操作历史和当前目录统计；
- 远程目录列表、进入目录、返回上级目录；
- 新建文件夹和删除文件/文件夹；
- 上传文件和上传进度；
- 下载文件和下载进度；
- 下载 `.part` 临时文件、断点续传；
- 下载完成后 SHA-256 校验；
- 本地下载目录选择；
- 本地文件夹列表、文件夹双击切换、选中文件直接上传；
- 当前传输任务状态显示。
- 左侧首页、文件、传输页面导航。

## Qt Creator + CMake

1. 使用 Qt Creator 打开本目录中的 `CMakeLists.txt`；
2. 选择 Qt 5.15 或 Qt 6 Desktop Kit；
3. 配置并构建 `netdisk_qt_client`；
4. 启动服务端后运行客户端；
5. 默认连接 `127.0.0.1:2000`，也可以在登录页修改地址和端口。

## qmake

```bash
qmake netdisk_qt_client.pro
make
```

Windows 下可以在 Qt 命令行执行：

```bat
qmake netdisk_qt_client.pro
nmake
```

## 注意事项

当前服务端协议使用空格分隔命令，因此用户名、密码和文件名暂时不能包含空格。开发环境客户端会忽略自签名证书错误；正式部署时应配置 CA 验证并删除 `ignoreSslErrors()`。

当前服务端上传协议会为每次上传创建新的临时对象，Qt 客户端已实现下载 `.part` 续传；上传断点续传需要服务端进一步增加 `PUT offset` 协议和临时文件恢复逻辑。
